## Структура репозиторію

### `.pdf та .doc`
Оформлений звіт до лабораторної роботи.

### `Фото`
Скріншот виконання завдання 1.1.
https://github.com/tatarchukvolodumer-dotcom/ak2_lab1_io42_tatarchuk/blob/main/photo_2026-09-14_16-58-50.jpg
### `history/`
Історія команд, виконаних під час лабораторної роботи та оформлена для зручного читанння.

### `origin_history/`
Оригінальні, невідредаговані файли історії команд терміналів.

### `scripts/`
Bash-скрипти, створені під час виконання лабораторної роботи.

Для завдання з автоматизації використано **варіант 4** (`4216 % 6 = 4`).

Скрипти:
- `1.sh` — рекурсивно видаляє порожні файли, після чого порожні директорії;
- 2.sh` —— запускає `1.sh` у новому вікні терміналу та залишає його відкритим після завершення.
- test.sh — скрипт, що створює об'єкти для тестування виконання завдання.
